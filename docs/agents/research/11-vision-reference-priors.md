# Digest: Should the agent loop carry a "vision" (reference expectation) of correct behavior?

Context anchored in `docs/agents/loop-engineering-analysis.md` §II.1 (the dt-artifact fooled agent, orchestrator, AND human — the human's "gaps too large" prior was wrong and the bug confirmed it), §II.2 (human-inputs catalog: the load-bearing human faculty was *doubting a passing result*), Part IV.1 (general detectors, not pre-enumerated failure maps).

## Thread 1 — Expectation-based anomaly detection (surprise as a monitoring signal)

This is a mature, technical literature. The "compare observation against an internal forward model, alarm on prediction error" pattern the user describes IS a standard robotics architecture:

- **Classic execution monitoring**: Pettersson, ["Execution monitoring in robotics: A survey"](https://www.sciencedirect.com/science/article/abs/pii/S092188900500134X) (Robotics and Autonomous Systems, 2005) defines execution monitoring exactly as the user's intuition: *"identifying discrepancies between observations of the actual world and the predictions and expectations derived from its representation of the world."* Model-based variants compare each action's declared effects to post-execution observations — e.g. ["Plan execution monitoring through detection of unmet expectations about action outcomes"](https://ieeexplore.ieee.org/document/7139646/) (ICRA 2015) and semantic-knowledge monitoring ([Bouguerra et al., RAS 2008](https://www.sciencedirect.com/science/article/abs/pii/S0921889008001152)) which derives *implicit* expectations from domain knowledge — the closest classic analogue to "the literature says re-centering, so expect re-centering."
- **Prediction-error residuals, made fully technical**: active inference/free-energy is no longer just neuroscience framing — [Baioumy et al., "Fault-tolerant Control of Robot Manipulators with Sensory Faults using Unbiased Active Inference"](https://arxiv.org/abs/2104.01817) (ECC 2021; also [IWAI 2020](https://link.springer.com/chapter/10.1007/978-3-030-64919-7_3)) uses sensory prediction errors in the free-energy as residuals with probabilistically robust thresholds for fault detection/isolation. So "predictive processing" has been operationalized as residual generation — the same mathematical object as a Kalman innovation test.
- **Learned world-model surprise (current wave)**: [FoMo-FD](https://arxiv.org/html/2607.27511) (2026) — flow-matching world model scores observations against learned *nominal dynamics* for surgical imitation policies; [Foresight](https://arxiv.org/pdf/2606.23085) (2026) — action-conditioned world-model latents for long-horizon manipulation failure detection; [SAFECAST](https://arxiv.org/html/2608.04246) (2026) — contrast-set-calibrated VLA failure probes; [Pre-VLA](https://arxiv.org/pdf/2605.22446) (2026) — preemptive runtime verification of VLA/world-model rollouts. Also ["Worth Remembering: Surprise-Gated Robot Episodic Memory"](https://arxiv.org/html/2606.03787v1) (2026): KL divergence between world-model prior and posterior as a *gate on what to remember* — surprise as a salience signal, directly relevant to the loop's memory ratchet.
- LSTM prediction-error thresholds for abnormal robot movement: [Journal of Intelligent & Robotic Systems, 2021](https://link.springer.com/article/10.1007/s10846-021-01496-x).

**Takeaway**: "expectation → residual → threshold → alarm" is textbook. What all of these have that the naive "vision" lacks: the expectation is a *calibrated distribution* (with thresholds derived from nominal variance), not a point image. The alarm triggers *investigation/isolation*, never acceptance.

## Thread 2 — Reference behavior specs, golden runs, pre-registration

- **Behavior envelopes are a formalized engineering practice**: Signal Temporal Logic runtime monitoring for CPS — [Bartocci/Deshmukh/Donzé et al., "Specification-Based Monitoring of Cyber-Physical Systems"](http://www-verimag.imag.fr/PEOPLE/maler/Papers/monitor-RV-chapter.pdf) (RV chapter); [Conformal Prediction for STL Runtime Verification](https://arxiv.org/pdf/2211.01539) (2022, gives statistically valid alarm thresholds); [survey of RV beyond software](https://arxiv.org/pdf/1811.06740). STL gives *quantitative robustness margins* — "how far inside the envelope was this run" — i.e. a continuous hold-quality-style metric over trajectories, exactly the shape of check the grasp harness's cage metric evolved toward.
- **Design-by-contract for physical behavior**: assume-guarantee contracts for CPS — [Stochastic A/G Contracts (StSTL)](https://arxiv.org/abs/1705.09316) (ACM TECS 2019), [CHASE](https://ieeexplore.ieee.org/document/8342122/) (DATE 2018), [Pacti](https://arxiv.org/pdf/2303.17751) (2023), [CROME for robotic missions](https://arxiv.org/pdf/2306.08144). The relevant idea: a component's *expected behavior is a first-class, checkable artifact* separate from its implementation.
- **Golden runs**: the practice of pinning a known-correct run and asserting future behavior against it — ["Specification-guided Golden Run for Analysis of Robustness Testing Results"](https://www.researchgate.net/publication/261348235_Specification-guided_Golden_Run_for_Analysis_of_Robustness_Testing_Results) (dependability testing); [golden test vectors](https://gophertrunk.org/reference/golden-test-vectors/) / [golden datasets for LLM regression](https://langfuse.com/resources/engineering/golden-dataset-evaluation). The important refinement from the dependability literature: a raw golden-run trace is brittle; a *specification-guided* golden run (assert the properties, not the pixels) is the durable form.
- **Pre-registration for agents — the strongest recent thread**: ["Preregistration for Experiments with AI Agents"](https://arxiv.org/abs/2606.11217) (2026) — a template requiring advance commitment to hypotheses/methods/analyses plus disclosure of pilot history, creating an auditable record. ["Agentic AI Scientists Are Not Built For Autonomous Scientific Discovery"](https://arxiv.org/abs/2605.08956) (2026) argues automated hypothesis-testing loops amplify selective reporting by orders of magnitude and proposes *machine-readable hypothesis registration before any simulation runs* — noting this is trivially enforceable via an API call in the pipeline (unlike for humans). ["Computational references are not experiments"](https://arxiv.org/pdf/2606.23725) (Vepa, 2026, materials science) demonstrates the mechanism: lock model predictions *before* the test so results can't be unconsciously adjusted toward them. Also [FirstResearch: auditable question formation](https://arxiv.org/pdf/2607.05682) and ["The Calibration Turn in AI-Assisted Research"](https://arxiv.org/pdf/2606.31273) (evidence-licensed claims — claims only as strong as the validation actually performed, which is precisely the §IV.2 "measurement validity as a first-class column" idea).

**Takeaway**: pre-registered qualitative prediction is not exotic — it is the emerging consensus fix for exactly the failure class this project hit (agent loop confirming its own/its operator's hypothesis). And its enforcement is *easier* for agents than humans.

## Thread 3 — Literature-derived priors as expectations

Thinner but real:

- **Literature-grounded hypothesis systems**: [HypER](https://www.researchgate.net/publication/392736342_HypER_Literature-grounded_Hypothesis_Generation_and_Distillation_with_Provenance) (2025) — provenance-tracked reasoning chains from literature, with validation that filters misleading connections; [survey of LLM scientific agents](https://arxiv.org/pdf/2503.24047) (2025) and [Agentic Science survey](https://arxiv.org/pdf/2508.14111) (2025) cover retrieval-as-deliberate-reasoning-step before hypothesis commitment. These are priors for *generation*, though — almost nothing does the inverse move the user wants: **literature prior as an anomaly detector on the agent's own results** ("published behavior says X; my sim shows ¬X; flag before believing"). The closest classic pattern is the semantic-knowledge execution monitoring above (expectations derived from a knowledge base, matched against observation). This inverse use appears to be a genuine gap — i.e., cheap novelty for this project, not a solved problem to import.
- **Concrete domain anchor exists**: the [Yale OpenHand project](https://www.eng.yale.edu/grablab/openhand/) (Ma & Dollar, [ICRA 2017 paper](https://www.semanticscholar.org/paper/c4e1adb50538532d93cfd929b34a860238a683e2)) and the underactuated-hand literature ([objective evaluation of underactuated gripper designs](https://arxiv.org/pdf/1601.04547)) do document adaptive/self-conforming grasp behavior explicitly enough to write a textual expectation ("passive mechanical adaptation wraps and centers the object under tendon tension"). The grasp-iter2 outcome (faithful PRB hand re-centers; the stand-in ejected) is a worked example where this prior *was correct* and would have flagged the stand-in artifact a full iteration earlier.
- **Precedent for defeasible simulation priors**: NIST **CAMEO** — [Kusne et al., "On-the-fly closed-loop materials discovery via Bayesian active learning"](https://www.nature.com/articles/s41467-020-19597-w) (Nature Communications, 2020). DFT-computed phase maps seed the Bayesian prior for phase-mapping; live diffraction measurements update and can override it. This is the canonical form: **the prior is an initial weight, structurally guaranteed to be outvotable by data**, and it demonstrably accelerated discovery rather than biasing it.

## Thread 4 — The bias risk

The evidence that a carelessly injected prior corrupts judgment is strong:

- **Anchoring in LLM judges is severe and prompt-resistant**: ["Anchoring Bias in LLM-as-a-Judge Systems: Prior Scores Compromise Evaluation Independence"](https://arxiv.org/abs/2608.25869) (2026) — prior scores included even as *context metadata* block 48% of error corrections and flip ~10% of correct judgments toward an assigned wrong label; neither CoT nor an explicit "disregard the metadata" warning removes the effect. Broader: [LLMs show bias-consistent behavior in 17.8–57.3% of instances](https://arxiv.org/pdf/2410.15413) across anchoring/confirmation/framing; [Bias in the Loop (SE judges)](https://arxiv.org/html/2604.16790v1); [CyclicJudge mitigation](https://arxiv.org/pdf/2603.01865). **Implication: the expectation must never sit in the same context as the scoring/verdict step.**
- **The full-scale precedent of a wrong prior spuriously confirmed**: A-Lab — Nature 2023 [autonomous lab paper](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10700133/), [Palgrave et al. critique](https://www.chemistryworld.com/news/new-analysis-raises-doubts-over-autonomous-labs-materials-discoveries/4018791.article), [Cheetham & Seshadri perspective](https://pubs.acs.org/doi/10.1021/acs.chemmater.4c00643) (Chem. Mater. 2024), [Nature correction, Jan 2026](https://cen.acs.org/research-integrity/Nature-robot-chemist-paper-corrected/104/web/2026/01): the loop's Rietveld auto-analysis "confirmed" the prior expectation of novel phases that were actually known/disordered — expectation + weak verifier = confirmation at scale. (Already in the repo's Part VI; the 2026 correction closes the arc.)
- **When priors help vs. hurt (Bayesian framing)**: [prior elicitation critical review](https://arxiv.org/pdf/2112.07090), [expert agreement effects on inference](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9568464/), [prior robustness / methodological flexibility](https://www.bayesianspectacles.org/preprint-practical-challenges-and-methodological-flexibility-in-prior-elicitation/). Distilled: priors help when data is expensive/sparse (they direct attention — CAMEO), hurt when the likelihood is weak or the verifier is corruptible (they then dominate the posterior — A-Lab, and this project's dt-artifact where the "measurement" itself was broken so the wrong prior faced no resistance). The prior-robustness move — check whether the conclusion survives a *class* of priors including "no prior" — is directly portable.

## Thread 5 — Can VLMs/agents compare behavior to a reference render?

- **Rollout-vs-expectation via generative models**: [MinD](https://arxiv.org/pdf/2506.18897) (2025) compares real execution to predicted video rollouts, catching missed grasps/collisions; [RoboWorld](https://arxiv.org/html/2607.01060) (2026) pairs a video world model with a task-progress-aware VLM judge; [RoboGaze](https://arxiv.org/html/2606.28385) (2026) explicitly warns that generated reference video must be *physically plausible*, not just visually real — the mechanism-fidelity lesson again.
- **VLM success/progress judging**: [SuccessVQA](https://arxiv.org/pdf/2303.07280) (Du et al., 2023); [Generative Value Learning](https://generative-value-learning.github.io/) (Ma et al., 2024) — VLMs as in-context value functions via frame temporal-ordering, conditionable on reference demonstrations (the closest existing thing to "does this rollout look like the reference clip"); [ViVa](https://arxiv.org/abs/2604.08168) (2026); [ROVER](https://arxiv.org/pdf/2508.01943); [subgoal-level VLM evaluation](https://arxiv.org/html/2509.19524); [video failure detection with task knowledge](https://arxiv.org/html/2508.18705).
- **But**: these operate at task/subgoal granularity. Nothing found validates VLM judgment at the contact-dynamics granularity where this project's artifacts live (finger vibration, one-finger precarious holds, punch-through) — consistent with the repo's own §II.2 finding ("VLMs weak on near-miss/contact"). Reference *clips* are the weakest of the three forms for this project today.

# Synthesized recommendation

**Yes — add a "vision" component, but as a pre-registered, defeasible expectation record that gates *investigation*, never *acceptance*, and that is kept out of the scorer's context.** The literature splits cleanly: expectation-as-residual-generator (Thread 1) and expectation-as-preregistration (Thread 2) are proven wins; expectation-as-judge-context (Thread 4) is a proven loss. The user's instinct is a real architecture — the mistake would be implementing it as a prompt to the evaluator.

**Form — three components, in priority order:**

1. **Pre-registered qualitative prediction (highest value, near-zero cost).** Before each experiment runs, the agent writes a short structured record: *expected qualitative behavior* (e.g., "fingers wrap, ball re-centers toward palm, hold survives inversion"), *literature/architecture anchor with citation* (OpenHand → passive re-centering; Lee SO(3) → known singularity at yaw=π), *what deviation would look like*, and *a confidence tag* (literature-backed / analogy / guess). This is exactly arXiv 2606.11217 / 2605.08956's mechanism, enforceable as a pipeline step (the record must exist, timestamped, before results). It converts the human's tacit "vision" into text — and answers question (b): yes, it can be technical enough, precisely *because* this is engineering with reference designs (memory note: "engineering, not science"). The grasp experiment is the proof case in both directions: a pre-registered "Yale hands re-center per Ma & Dollar 2017" would have flagged the stand-in's ejection one iteration early, and a pre-registered "gaps too large" (human prior) would have been *on the record as a prediction* when the dt-artifact "confirmed" it — auditable, hence catchable.

2. **Expectation-violation as a general detector (extends Part IV.1's detector set).** Add one detector to the existing ~6–10: *"result contradicts a literature-anchored expectation → LOCALIZE before believing either side."* Crucially symmetric: a violation can mean (a) the sim found something real, (b) the sim is broken, or (c) the prior is wrong — and the resolution is always the existing machinery (perturbation/convergence gate, mechanism-fidelity check), never the prior itself. This is the CAMEO shape: prior as outvotable initial weight. It fits the repo's grown-not-prebuilt ratchet: each resolved violation becomes a ledger entry.

3. **Golden runs / behavior envelopes for regression (mechanical, not textual).** Once a behavior is validated (the 96/96 compliant-capture envelope, the PRB re-centering), pin it as a specification-guided golden run: assert STL-style properties over the trajectory (re-centering displacement decreases monotonically after contact; hold-quality ≥ x through inversion), not raw traces. This is the "vision" in its most mechanized form and slots into the existing PASS/FAIL harness culture.

**Do NOT build (yet):** reference-clip comparison via VLM/world-model. The tooling (GVL, RoboWorld) exists but is unvalidated at contact-dynamics granularity — the exact granularity where this project's artifacts hide — and the project's own evidence says VLMs miss near-miss/contact failures. Defer with a named trigger (per Part V's earn-your-complexity rule): revisit if a textual expectation-violation is ever missed because it was only visible as motion.

**Safeguards against bias (each maps to an observed failure):**

- **Context isolation**: the expectation record is never in the judge/scorer's context (arXiv 2608.25869: even "disregard this" warnings don't neutralize anchors). The scorer measures; a *separate* step diffs measurement against the pre-registered record.
- **Asymmetric authority**: a violated expectation can *raise* scrutiny (trigger the convergence gate, mechanism check); a *confirmed* expectation lowers nothing — all standard gates still run. Confirmation is not evidence of validity (dt-artifact and A-Lab both confirmed wrong priors through broken verifiers).
- **Provenance + confidence tags**: literature-backed expectations cite the source (HypER-style); untagged vibes don't get detector status. This keeps the "literature-prior critic" from laundering the agent's own guesses as authority.
- **Prior-robustness check on disputes**: when prior and result genuinely conflict after localization, ask "does the conclusion survive with no prior?" — if the verdict depends on the prior, it isn't earned yet.
- **The ratchet closes the loop**: every wrong pre-registered expectation is itself a ledger entry ("OpenHand ejection expectation was a stand-in artifact, not a mechanism property") — the vision improves with the same machinery as everything else.

One-line answer to (a): a vision helps *iff* it is written down before the run, cited where possible, kept away from the scorer, and only ever allowed to demand more evidence — never to supply it.
